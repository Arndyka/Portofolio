# Arnoldus portfolio design

Approved direction: Engineering, AI & Banking Technology. The owner approved the proposed design and requested execution of all work on 15 October 2026. Source destination: Arndyka/Portofolio; hosting: GitHub Pages.

## Experience
Indonesian default with a complete English version. A spacious navy and ivory editorial home introduces Arnoldus, then presents selected projects, experience, education, capabilities, learning, and contact. Teal accents, original portrait, restrained motion, and custom illustrative diagrams establish identity. Project cards link to dedicated case studies with context, role, approach, deliverables and an honest evidence boundary. Category filters and a mobile menu enhance static content.

## Content
Use verified CV/portfolio facts and project documentation. Feature AI-Powered Access/session Monitoring, FMCW river monitoring, stunting dashboard, IoT curtains, antenna research, and laboratory practicum work. Team projects distinguish individual role from collective outcomes. Do not invent impact statistics, live production status, customers or awards. Azure AI-900 preparation is a course completion, not Microsoft certification. Education GPA is attributed to the supplied CV. ODP start month and internal title are omitted because unverified.

Never inspect or use Beehoon, Tugas Kelompoknya Angel Alpro, or PENGELUARAN. Publish only curated prose and the owner's portrait; no source work documents, customer data, internal screenshots, databases, credentials, identity documents, exact home address, or other people's contact details. Contact uses the professional email and LinkedIn from the CV. Do not publish old CV PDFs containing personal details; provide a print-friendly profile instead.

## Architecture
Dependency-free static HTML/CSS/JS generated by Node from bilingual content. Output dist includes both locales and project routes. Configurable base path defaults to /Portofolio/. JS only enhances filtering/menu; all content and links remain available without it. Language links preserve the current case study. Metadata, canonical URLs, sitemap, robots and social SVG included. Public unknown routes show a helpful 404.

## Acceptance
Desktop and 390/320 px mobile: no overflow, readable content, keyboard access, visible focus. Mobile navigation closes on selection/Escape. Filters expose selected state and update visible project count. Reduced motion respected. All assets and local links resolve under the repository path. Test both locales and every project route, accessibility on representative pages, no-JS access and language switching. Publish only dist using GitHub Actions; verify the deployment and public URL. GitHub hosting explicitly overrides the generic Sites hosting default.
